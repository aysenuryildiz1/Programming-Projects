# Task Management Dashboard

A web-based task management panel developed using HTML, CSS, and JavaScript.

## About The Project

This project is a task management dashboard designed to demonstrate JavaScript event handling mechanisms. Users can add, delete, complete, and filter tasks through an interactive interface.

The project structure is divided into separate files to improve code readability and maintainability. Important sections are explained with comments.

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks
- Interactive task management interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts

- Event Handling
- Event Delegation
- CustomEvent
- DOM Manipulation
- Parent Element Event Management

## Implementation Details

**Event Delegation:** Used for task deletion and completion operations. Instead of adding separate event listeners to each button, events are managed through a parent element.

**CustomEvent:** Used to create a custom event system and demonstrate custom event-based communication.
